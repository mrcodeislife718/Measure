# Measure — Portfolio Proof Contract

**Track:** Commercial evaluation / verification platform

Measure is complete only when it can evaluate real external systems reproducibly, resist benchmark gaming, preserve evidence, deploy safely, and demonstrate customer value.

Required proof: end-to-end evaluations against real systems; deterministic verifier and replay tests; adversarial tests for contamination, gaming, malformed evidence, tenant isolation, SSRF, verifier failure, and dependency drift; benchmark validity and reproducibility comparisons; security evidence; hosted/private-runner deployment evidence; real users and paid evaluations where commercialized.

Every published claim must map to immutable evidence, a verifier result, benchmark artifact, or customer outcome.

**Next proof target:** evaluate multiple independent real systems on the same preregistered world, replay results from stored evidence, inject gaming/failure attempts, and publish supported claims, limitations, unknowns, and reproducibility artifacts.
